  • A2A formalizes extension governance as protocol matures
    Vinay Ramesh lands PR #1488 establishing lifecycle stages (Draft→Experimental→Stable→Deprecated) and TSC oversight for extensions. Combined with AWS joining the TSC last week, A2A is clearly entering enterprise-ready governance phase. Read analysis →

    Ilya Grigorik proposes PR #250 enabling AI agents to prove customer eligibility (student status, memberships, employee programs) via cryptographic claims without exposing identity data. Critical for full shopping autonomy. Read analysis →

    PR #3525 adds fail-closed behavior on symlink traversal outside configured roots, with PR #3526 adding stable reason codes. Following February's security audit, the MCP team is systematically hardening filesystem boundaries.

    Today's commits include Ollama onboarding improvements (1435fce), env proxy bootstrap fixes (87876a3), and owner-only tool policy fallbacks (62d5df2). The team is clearly focused on making provider fallbacks bulletproof across diverse deployment scenarios.
